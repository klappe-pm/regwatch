# Register

These are the register files of the synthetic example, one of each kind regwatch reads. They show the shape of each file; the rules for every field are in [data files](../../docs/reference/data-files.md). All of the content is invented. Replace it with your own when you start a real register, and never commit a real register to a public repository.

## Files

| file | holds |
| --- | --- |
| `obligations.csv` | seven invented obligations, one row each |
| `jurisdictions.json` | two countries, three regions, and an aggregate marker |
| `categories.json` | five categories that obligations and products share |
| `sources.json` | five sources, one for each mechanism including `manual` |
| `portfolio.json` | the example company and three invented products |
| `detail.json` | human-written detail for three obligations; the others have none, on purpose |
| `changelog.json` | three curated change log events |
| `enforcement.json` | two enforcement themes |
| `themes.json` | two impact themes |
