# how-to-guides

How-to guides are recipes. Each one solves a specific development problem for a reader who already knows the codebase and wants the steps, with the minimum of explanation along the way. They assume more than a tutorial and promise less: a guide gets you to one outcome, and links to the reference pages for the details it skips.

## pages

- [run the tests](run-the-tests.md): the test suite, the coverage report, and the lint, format and type checks a change must pass.
- [add a source mechanism](add-a-source-mechanism.md): teach `check` to read a new kind of source, with the tests it needs.
