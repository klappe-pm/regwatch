# tutorials

Tutorials are lessons. Each one takes a reader who has not done the task before through it from start to finish, on one path, explaining only what that path needs. They exist so a new user succeeds at something real on the first try; they are not the place to look up an option or to understand a design, and they link out to the reference and explanation pages for that.
