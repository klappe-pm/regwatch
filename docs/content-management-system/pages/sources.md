# sources

The Sources page of the local application: the sources you watch with their last status, and the catalogue to choose more from.

## `header`

- `title`: Sources
- `description`: The sources you watch, with their status from the last stored snapshot, and the catalogue to choose more from. Adding a source writes it to your sources file, as regwatch sources add does.

## `mine`

- `title`: Your Sources
- `filter-label`: Filter your sources
- `filter-placeholder`: Filter
- `no-match`: No source matches this filter.
- `empty`: Add sources from the catalogue below.
- `table`: Your sources
- `source`: Source
- `jurisdiction`: Jurisdiction
- `mechanism`: Mechanism
- `cadence`: Cadence
- `last-status`: Last Status

## `catalogue`

- `title`: Catalogue
- `count-one`: {shown} of {total} source
- `count-many`: {shown} of {total} sources
- `search`: Search the catalogue
- `search-placeholder`: Name, publisher or jurisdiction
- `category`: Category
- `all-categories`: All categories
- `region`: Region
- `all-regions`: All regions
- `kind`: Kind
- `all-kinds`: All kinds
- `access`: Access
- `any-access`: Any access
- `empty`: No catalogue source matches this search and these filters.
- `results`: Catalogue search results
- `group-table`: {group} sources
- `source`: Source
- `watching`: Watching
- `add`: Add
- `add-label`: Add {name}
- `open-keys`: Open Keys

## `messages`

- `added`: Added {name} to your sources.
- `already`: {name} is already in your sources.
- `jurisdiction`: Added the jurisdiction {jurisdictions} to your register.
- `needs-key`: It needs a key; set one on the Keys page.
- `add-failed`: The source could not be added.
