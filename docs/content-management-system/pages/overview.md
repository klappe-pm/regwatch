# overview

The first page of the local application: counts from the last source check, the highest priority changes, supply chain sources, flagged sources and obligations that take effect soon.

## `header`

- `title`: Overview
- `description`: Source checks against stored snapshots, as of {generated}.

## `figures`

- `new`: New
- `changed`: Changed
- `suspicious`: Suspicious
- `failing`: Failing
- `next-run`: Next Run
- `not-scheduled`: Not scheduled

## `regulatory`

- `title`: Regulatory Changes
- `empty`: No obligation touches a product in your portfolio yet.
- `table`: Highest priority changes
- `severity`: Severity
- `obligation`: Obligation
- `product`: Product
- `effective`: Effective

## `supply`

- `title`: Supply Chain
- `empty-before`: Input cost and packaging sources you watch will appear here with their last status. Choose them on the
- `empty-link`: Sources
- `empty-after`: page from the Ingredients Supply, Packaging Materials and Commodities and Forecasts categories.
- `table`: Supply chain sources
- `source`: Source
- `category`: Category
- `last-status`: Last Status
- `note`: Prices and forecasts are not read yet; each source shows whether it changed.

## `review`

- `title`: Sources Needing Review
- `empty`: All {count} sources match their accepted baseline.
- `table`: Sources needing review
- `source`: Source
- `status`: Status

## `upcoming`

- `title`: Effective Within 90 Days
- `empty`: No obligation takes effect in the next 90 days.
- `table`: Obligations effective within 90 days
- `date`: Date
- `obligation`: Obligation
- `status`: Status
