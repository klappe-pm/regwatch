# shell

The navigation rail of the local application and its search.

## `nav`

- `label`: Main
- `skip`: Skip to content
- `overview`: Overview
- `changes`: Changes
- `sources`: Sources
- `obligations`: Obligations
- `briefings`: Briefings
- `newsletters`: Newsletters
- `documents`: Documents
- `automations`: Automations
- `keys`: Keys
- `settings`: Settings
- `collapse`: Collapse
- `collapse-label`: Collapse navigation
- `expand-label`: Expand navigation

## `search`

- `label`: Search sources, changes and obligations
- `placeholder`: Search
- `results`: Search results
