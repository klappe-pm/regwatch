# ui

The words the shared parts of the local application show on every page: loading and empty states, premium notes, labels and the footer line.

## `state`

- `loading`: Loading
- `filled-by`: Filled by
- `not-checked`: Not checked
- `no-date`: No date
- `request-failed`: The request failed.
- `request-failed-status`: The request failed ({status}).

## `locked`

- `on-settings`: {feature} is a premium feature. Turn on premium features above to use it.
- `before-link`: {feature} is a premium feature. Turn premium on in
- `link`: Settings
- `between`: or with
- `command`: regwatch premium on
- `after`: .
- `premium`: Premium
- `premium-suffix`: {label} (premium)

## `tag`

- `generated`: Generated

## `actions`

- `download`: Download
- `markdown`: Markdown
- `html`: HTML
- `word`: Word
- `text`: Text
- `print`: Print or PDF

## `commands`

- `impact`: regwatch impact
- `sources-add`: regwatch sources add
- `check`: regwatch check
- `ingest`: regwatch ingest --fetch
- `list`: regwatch list
- `schedule-install`: regwatch schedule --install
- `schedule-hourly`: regwatch schedule --install --every hourly
- `run`: regwatch run
- `keys-set`: regwatch keys set

## `footer`

- `disclaimer`: Bev Watch flags candidates for human review. It is not legal advice.
- `version`: Version {version}.
